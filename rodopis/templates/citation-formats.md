# Citation formats

One line per source, pasted into the tree's citation field or into `genealogy/pending-tree-edits.md`. After the line, the grade from `rodopis/rules.md` (section "Confidence scale").

| Source | Format |
|---|---|
| Parish or civil register | `<register type> <parish/place>, <archive>, ref. <x>, <ID/DGS>, image <n>, p. <p>, entry <e>, URL` |
| Census | `Census <year>, <place>, house no. <n>, <archive>, fonds <f>, ref. <x>, sheet <s>, image <n>, URL` |
| Police registration / Meldezettel | `<registration type>, <city>, <archive>, <name as written>, born <year>, image <n>, URL` |
| Newspaper | `<title>, <place>, <date>, year <v>, no. <n>, p. <p>, column <c>, <digital library>, URL` |
| Book | `<author>, <title>, <place> <year>, p. <p>, <library or digital library>, URL` |
| Military record | `<record type>, <regiment>, <archive>, <fonds>, <box/folder>, image <n>, URL` |
| Holocaust database | `<database>, <record type>, <name as written>, born <date>, <transport/record ID>, URL` |
| Grave | `<cemetery>, <section/row/grave>, <inscription literally>, photo <file or URL>, <date seen>` |
| Archive reply | `<archive>, letter ref. <x> of <date>, to the researcher, <what it confirms>, file <path>` |
| Photo | `<owner or collection>, <description>, <photographer/studio>, <dating and how>, file <path>` |

Grade line: `Source: original | derivative. Information: primary | secondary. Confidence: Proven | Probable | Possible | Speculative. Reason: <one sentence>.`

Example (fictional): `Death register Ceske Budejovice St. Nicholas, State Regional Archive Trebon, ref. 123, image 45, p. 88, entry 12, https://... Source: original. Information: primary. Confidence: Proven. Reason: name, age 61 and house no. agree with the baptism of 1871.`
