# Member brief

What genealogy-agent sends to a member. A few lines; the know-how is in the member's definition.

```
Person: <full name>, tree ID <id>, folder genealogy/people/<slug>/
Key facts:
- <3-8 lines from status.md: dates, places, house numbers, parents, occupation, fate of the close family, corrected mistakes>
Gap: <one gap or one topic, as rod-auditor wrote it>
Scans: <paths, or "none">
Already searched: <source, years, result>
Return: your fixed output block, at most about 600 words.
```

Example (fictional person):

```
Person: Josef Novak, tree ID @I12@, folder genealogy/people/josef-novak-1871/
Key facts:
- born 3 March 1871 in Lomnice nad Luznici, house no. 45, father Jan Novak, cooper
- married 1898 in Trebon to Marie Svobodova
- died 1932 in Ceske Budejovice; death not yet from the original
Gap: [point 3] death and burial from the original -> rod-matriky
Scans: none
Already searched: matriky.online index for Ceske Budejovice 1930-1935, nothing under Novak Josef
```
